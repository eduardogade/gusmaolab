Why a standard error

A sample mean x‾\bar{x} varies from sample to sample, and the spread of its values is described by the standard error (Student 1908). For nn independent observations with standard deviation σ\sigma it is given in Equation 1.

SE(x‾)=σn(1) \mathrm{SE}(\bar{x}) = \frac{\sigma}{\sqrt{n}} \qquad(1)

The mean of a long list is steadier than the mean of a short one, and Equation 1 says by how much: four times as many observations halve the standard error.1

A synthetic experiment

The cell below draws samples of several sizes from one invented normal distribution, with a fixed seed, and measures the spread of their means. It uses only the Python standard library.

import math, random, statistics

SIZES = [4, 16, 64, 256]
REPEATS = 400
random.seed(20261114)

def sample_mean(n):
    return statistics.fmean(random.gauss(10.0, 2.0) for _ in range(n))

spread = {n: statistics.stdev(sample_mean(n) for _ in range(REPEATS)) for n in SIZES}
expected = {n: 2.0 / math.sqrt(n) for n in SIZES}
print({n: round(spread[n], 3) for n in SIZES})
{4: 1.053, 16: 0.484, 64: 0.241, 256: 0.127}

Figure 1 plots the measured spread against the value of Equation 1, and Table 1 lists both.

from IPython.display import SVG, display

W, H, left, bottom, top = 520, 260, 56, 220, 24
top_value = max(spread.values()) * 1.1
bars = []
for i, n in enumerate(SIZES):
    x = left + 28 + i * 112
    h = (bottom - top) * spread[n] / top_value
    e = (bottom - top) * expected[n] / top_value
    bars.append(
        f'<rect x="{x}" y="{bottom - h:.1f}" width="56" height="{h:.1f}" fill="currentColor" opacity="0.75"/>'
        f'<circle cx="{x + 28}" cy="{bottom - e:.1f}" r="6" fill="none" stroke="currentColor" stroke-width="2"/>'
        f'<text x="{x + 28}" y="{bottom + 22}" text-anchor="middle" font-size="14" fill="currentColor">n = {n}</text>'
    )
svg = (
    f'<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 {W} {H}" width="{W}" height="{H}" role="img">'
    f'<line x1="{left}" y1="{bottom}" x2="{W - 16}" y2="{bottom}" stroke="currentColor"/>'
    f'<line x1="{left}" y1="{top}" x2="{left}" y2="{bottom}" stroke="currentColor"/>'
    + "".join(bars) + "</svg>"
)
display(SVG(svg))
from IPython.display import Markdown, display

rows = ["| n | Measured spread | Formula, $\\sigma/\\sqrt{n}$ | Ratio |", "|---:|---:|---:|---:|"]
for n in SIZES:
    rows.append(f"| {n} | {spread[n]:.3f} | {expected[n]:.3f} | {spread[n] / expected[n]:.2f} |")
display(Markdown("\n".join(rows)))

The ratios in Table 1 are close to one: with 400 repeats the measured spread agrees with the formula to a few percent, which is what the method of resampling relies on (Efron and Tibshirani 1993).

What this shows, and what it does not

NoteWhat the test of this page is

That a document with seeded code can be executed on request, rendered without recomputing, and published through the site with its equations, figure, table, citations and notes intact. It does not show that the numbers above are right for any real data.

Rerunning the computation gives the same figures, because the seed is fixed. A different seed would give slightly different ones, and they would still agree with Equation 1.
